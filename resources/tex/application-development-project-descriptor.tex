	\section*{Authenticity}
	All parts of your submitted assessment \textbf{must} be completely your work. Do your best to complete this assessment without using  AI tools. You need to demonstrate to the course lecturer that you can meet the learning outcomes for this assessment. \\
	
	Learning to use AI tools is an important skill. While AI tools are powerful, you \textbf{must} be aware of the following:

	\begin{itemize}
		\item If you provide an AI tool with a prompt that is not refined enough, it may generate a not-so-useful response
		\item Do not trust the AI tool's responses blindly. You \textbf{must} still use your judgement and may need to do additional research to determine if the response is correct
		\item Acknowledge what AI tool you have used. In the assessment's repository \textbf{README.md} file, please include what prompt(s) you provided to the AI tool and how you used the response(s) to help you with your work
	\end{itemize}

	It also applies to code snippets retrieved from \textbf{StackOverflow} and \textbf{GitHub}. \\
	
	Failure to do this may result in a mark of \textbf{zero} for this assessment.

	\subsection*{Functionality - Learning Outcomes 1, 2 (25\%)}
	\begin{itemize}
		 \item \textbf{HackerNews API} application with the following functionality:
		 \begin{itemize}
			\item Data is fetch from the \href{https://github.com/HackerNews/API}{HackerNews API}.
			\item Display a spinner while the data is being fetched from the API.
			\item Responsive UI design using \textbf{Tailwind CSS}.
			\item \textbf{Story Features:}
			\begin{itemize}
				\item Display the 50 ask, best, job, new, show and top stories.
				\item For each story, display the title, by, text, time and a link to the story using the id. Here is an example link - \href{https://news.ycombinator.com/item?id=ID}{https://news.ycombinator.com/item?id=ID}, where ID is the story's id.
				\item Truncate the text to 100 characters and add a link that expands the text when clicked.
			\end{itemize}

			% \item \textbf{Polls Features:}
			% \begin{itemize}
			% 	\item Display 25 polls. Here is a link to the polls - \href{https://hnpolls.com}{https://hnpolls.com}. 
			% 	\item For each poll, display the id, title, by, time, parts (score and text) and a link to the poll using the id and title. Here is an example link - \href{https://hnpolls.com/poll/ID-TITLE}{https://hnpolls.com/poll/ID-TITLE}, where ID is the poll's id and TITLE is the poll's title.
			% \end{itemize}
	
			\item \textbf{Leader Features:}
			\begin{itemize}
				\item Display 100 leaders. Here is a link to the leaders - \href{https://news.ycombinator.com/leaders}{https://news.ycombinator.com/leaders}. 
				\item For each leader, display their id, karma, created, about and a link to their profile using the id. Here is an example link - \href{https://news.ycombinator.com/user?id=ID}{https://news.ycombinator.com/user?id=ID}, where ID is the user's id. 
			\end{itemize}
			\item \textbf{Favourites Features:}
			\begin{itemize}
				\item Display a heart icon next to the story or leader. Toggle the heart icon when clicked to add or remove the story or leader from favourites. 
				\item Display a list of favourite stories and leaders. 
				\item If no favourites are found, display a message indicating that no favourites were found.
			\end{itemize}
			\item \textbf{Search Features:}
			\begin{itemize}
				\item Search for stories by title or type.
				\item Search for leaders by id.
				\item The search should be case-insensitive and return results that contain the search term anywhere in the title, type or id.
				\item Display the search results in a list. 
				\item If no results are found, display a message indicating that no results were found.
			\end{itemize}
			\item \textbf{Sort Features:}
			\begin{itemize}
				\item Sort stories by time, score or type. 
				\item Sort leaders by karma or created. 
				\item The default sort order for stories is time and for leaders is karma.
			\end{itemize}
			\item Display the time and created in a human-readable format. 
			\item Select any five \textbf{Medium Features} from the list below:
			\begin{itemize}
				\item Hover effects on stories and leaders.
				\item Toggle between colour themes. 
				\item Display the domain name from the story's URL. For example, if the story's URL is \texttt{https://example.com/story}, display \texttt{example.com}.
				\item Display score-range badges with colours. For example, 0-100 is red, 101-500 is orange, 501-1000 is yellow, 1001-5000 is green and 5001+ is blue.
				\item Display type badges with colours. For example, ask is blue, best is green, job is yellow, new is purple, show is orange and top is red.
				\item Select and compare two leaders. Display their id, karma, created, about and a link to their profile using the id.
				\item Display karma-range badges with colours for leaders. For example, 0-100 is red, 101-500 is orange, 501-1000 is yellow, 1001-5000 is green and 5001+ is blue.
				\item For stories, toggle between list and grid view. The list view should display the title, by, text, time and a link to the story using the id. The grid view should display the title, by and a link to the story using the id.
			\end{itemize}	
			\item Select any two \textbf{Hard Features} from the list below:
			\begin{itemize}
				\item Display the stories and leaders in pages of 10 with "Previous" and "Next" navigation buttons.
				\item Display stories and leaders search history based on the search functionality.
				\item Display a graph of the karma for each leader. Display their id on the x-axis and karma on the y-axis.
				\item Display a list of recommended stories based on the user's favourites. The recommendations should be based on the user's favourites and the stories' type.
			  \end{itemize}	
		 \end{itemize}

		 \item \textbf{OpenTDB API} application with the following functionality:
		 \begin{itemize}
			\item Data is fetch from the \href{OpenTDB API}{https://opentdb.com/api\_config.php}.
			\item Display a spinner while the data is being fetched from the API.
			\item Responsive UI design using \textbf{Shadcn UI}.
			\item Create a new quiz by selecting the start date, end date, number of questions, category, difficulty and type.
			\item Display a list of past, current and future quizzes.
			\item Past and future quizzes are not playable.
			\item Play a quiz by selecting a current quiz from the list. The quiz should display the start date, end date, category, difficulty, type, questions, options and a submit button.
			\item Shuffle the questions and options for each quiz.
			\item Display the quiz results after submitting the quiz. Prompt the user to enter their name before displaying the results. The results should display the user's name, start date, end date, category, difficulty, type, questions, options, correct answer and score.
			\item Store the quiz results appropriately.
			\item Display the average score for each quiz.
			\item Display the total number of quizzes played.
			\item For each quiz, display the scores in a list.
			\item Select any three \textbf{Medium Features} from the list below:
			\begin{itemize}
				\item Display a progress bar and "Question X of Y" text while playing the quiz.
				\item Display category badges with colours. For example, general knowledge is blue, art is green, history is yellow, geography is purple, etc.
				\item Allow a user to retake a completed quiz.
				\item For each quiz, display a countdown timer per question. The timer should start at ten minutes. If the timer reaches 0, the quiz should automatically submit.
				\item Select and compare two users. Display their name, number of quizzes played and average score.
			 \end{itemize}	
		 \end{itemize}
		%  \item Deploy both applications to \textbf{Vercel}.
	\end{itemize}
